`turno doctor` names the fix for config.toml findings: `turno profile add <name>` for a profile that does not exist, else the line of config.toml to edit and what to write there (`turno config check` prints the same advice). A local server in `~/.claude.json` that mcp.toml serves runs outside mcpd until `turno mcp sync` replaces its entry, and `turno doctor --fix` now runs that sync. `turno doctor` reports the `env:NAME` and `${NAME}` references of mcp.toml that mcpd would resolve and that are not set, by name only, and checks the gateway token in every profile's config even without `mcp-managed.json`. `turno run` without a profile lists `auto` first in the picker, named with the profile the folder resolves to (`auto (work)`). `turno uninstall --purge` also removes turno's state, caches and installed MCP servers after the same confirmation (no undo after it); without `--purge` nothing changes. Faster: the status line, `turno auto` and `turno resolve` find a worktree's main repository by reading `.git` files instead of running git, and `turno doctor --summary`, `turno uninstall` and `turno mcp log` no longer load the gateway or the MCP SDK.
