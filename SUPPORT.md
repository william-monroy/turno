# Getting help

- **Questions and ideas**: GitHub Discussions (there is an "Español" category for questions in
  Spanish).
- **Bugs**: an issue with the bug form. Run `turno doctor` first and paste its output, with
  tokens and personal paths removed.
- **Security issues**: never in public; see [SECURITY.md](SECURITY.md).

turno is maintained by one person in their spare time. There is no paid support and no
response-time promise outside security reports.
