This page lists every key `~/.config/turno/config.toml` may hold. turno warns about a key it does not know and ignores it.

`turno config set <key> <value>` changes a value without losing the file's comments, `turno config check` parses every config file, and `turno config path` says where each one lives.

## Keys you set with turno config

| Key | What it does |
| --- | --- |
| `system` | profile the plain claude command (~/.claude) is logged into; "" for none (then turno auto needs a rule) |
| `default` | Claude Code profile for folders without a rule |
| `fallback` | Claude Code profile used while the assigned one is exhausted (opt-in) |
| `agents.<agent>.default` | the same for codex, copilot or cursor |
| `agents.<agent>.fallback` | the same for codex, copilot or cursor (opt-in) |
| `icons` | auto, nerd or unicode |
| `nerd_terminals` | terminals whose font draws Nerd icons |
| `update_check` | true or false: look for new turno releases once a day |
| `hints` | true or false: print the next step after a command that writes |
| `open.chrome_dir` | folder of the isolated Chrome profiles |
| `mcpd.port` | port of the MCP gateway |
| `mcpd.call_log` | true or false: keep the log of tool calls (turno mcp log) |
| `mcpd.max_request_body` | largest request mcpd accepts, like "64MiB" (default 32MiB) |
| `mcpd.idle_under_pressure` | idle limit of MCP servers while memory is low, like "5m" (default), or false |
| `profiles.<name>.color` | status line pill color |
| `profiles.<name>.browser` | chrome or default |

## Keys turno writes for you

Profiles and folder rules have their own commands (`turno profile add`, `turno profile assign`), and a rule's server set is edited in the file.

| Key | What it does |
| --- | --- |
| `profiles.<name>.agent` | the agent of a profile that is not Claude Code: codex, copilot or cursor (set by turno profile add --agent) |
| `projects[].path` | the folder a rule applies to, and everything under it |
| `projects[].profile` | the profile sessions in that folder use (set by turno profile assign) |
| `projects[].mcp` | keep only these MCP servers for sessions in that folder, by their name in mcp.toml |
| `projects[].mcp_deny` | hide these MCP servers from sessions in that folder |

## An example

```toml title="~/.config/turno/config.toml"
system = "personal"     # account the plain `claude` command uses ("" for none)
default = "personal"    # profile for folders without a rule

[profiles.work]
color = "violet"        # status line pill
[profiles.cx]
agent = "codex"

[[projects]]
path = "~/code/acme"
profile = "work"

[[projects]]
path = "~/code/oss"
mcp_deny = ["mail"]     # sessions here see every MCP server but mail

[mcpd]
port = 47821
```
