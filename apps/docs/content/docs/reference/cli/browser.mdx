Developer tool: compare browser engines (needs turno-browser)

```text title="turno browser --help"
Usage:
  turno browser identities [--json]  list browser identities and whether they
                                     are in use
  turno browser add <id> [--timezone <zone>] [--locale <tag>] [--languages
      <tag,...>] [--region <CC>] [--health-url <url> --health-text <text>]
      [--dry-run]
                                     create an identity (pinned to this time
                                     zone) and print its mcp.toml block
  turno browser show <id> [--json]   an identity's settings, session health and
                                     who holds it
  turno browser set <id> [--timezone <zone>] [--locale <tag>] [--languages
      <tag,...>] [--region <CC>] [--health-url <url>] [--health-text <text>]
      [--health-selector <css>] [--no-health] [--dry-run]
                                     change an identity's identity.json (an
                                     empty value removes a setting)
  turno browser doctor [--fix] [--no-launch] [--json]
                                     check Chrome, a test launch and every
                                     identity (settings, lock, sign-in), with
                                     fixes
  turno browser reputation [<id>] [--json]
                                     challenges each identity met per site
                                     (captcha, verify it's you, block) and their
                                     trend
  turno browser remove <id> [--dry-run]
                                     delete an identity and its saved logins
  turno browser login <id> [--url <url>]
                                     open the identity's Chrome to sign in by
                                     hand once
  turno browser bench [--engine <name>]... [--url <url>]... [--only-urls]
      [--yes] [--json]
                                     check how each browser engine loads
                                     reference test pages and your URLs (asks
                                     first)

A developer diagnostic for browser engine compatibility. It needs the separate
turno-browser package (npm install --global turno-browser).
Identities are persistent Chrome profiles served by turno-browser-mcp, one session at a time
through mcpd; turno identity manages them too (browser:<id>). Ids use lowercase letters,
digits, "-" and "_", for example "school".

Examples:
  $ turno browser identities
  $ turno browser add school --languages es-MX,es,en
  $ turno browser show school
  $ turno browser set school --health-url https://mail.example.com/ --health-text Inbox
  $ turno browser login school --url https://example.com
  $ turno browser doctor --fix
  $ turno browser reputation school --json
  $ turno browser remove school --dry-run
  $ turno browser bench --only-urls --url https://example.com --yes
```
