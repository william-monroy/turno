This page lists every command of the `turno` CLI. Each one has its own page with the exact text `turno <command> --help` prints.

Commands that only read take `--json`. Commands that write take `--dry-run`, keep a copy of each file they change, and print the `turno undo <stamp>` that puts it back.

## turno help

This is what `turno help` prints:

```text title="turno help"
turno: one MCP gateway and per-folder accounts for Claude Code, Codex, Copilot CLI and Cursor CLI.

Start here: turno init, or turno demo to try turno in a throwaway HOME.

Usage
  turno <command> [flags]    a command below; turno <command> --help shows its flags
  turno <profile> [args...]  open that profile with its agent; the arguments after it go to the
                             agent

Get started
  init        set turno up in one step: find agents, profiles, folders and MCP servers, show the
              diff, write it (one undo)
  demo        try turno in a throwaway HOME: two profiles, a gateway and the status line (removed on
              exit)

Start an agent
  run         open a profile with its agent (turno <profile> is the short form), or auto
  auto        open the agent with the account assigned to this folder (turno-auto)

Accounts
  profile     accounts (profiles) for each agent: list, add, repair, remove, and which folders use
              each
  limit       usage limits of each account, and the exhausted marks that move projects to the
              fallback
  session     live Claude Code sessions, and moving one to another account
  open        open a claude.ai link with an account (default: the session's)

MCP servers and outside services
  mcp         MCP servers behind the lazy gateway, and the gateway daemon itself
  identity    who acts on outside services: service accounts (linear:work) and browser identities
              (browser:school)
  secret      store MCP secrets in the Keychain (macOS) or the Secret Service (Linux)

Look
  ui          the status line, its font and icons in every terminal

Maintenance
  status      one screen with everything: this folder, profiles and usage, sessions, mcpd and the
              look
  doctor      check everything (system, config, profiles, MCP, look, mcpd) and fix what is safe to
              fix
  config      read and change config.toml without losing its comments; check every config file
  undo        list recent changes turno made to your files, and put any of them back
  upgrade     update turno to the newest release (or check for one)
  uninstall   remove the service, launchers, status line and MCP entries turno set up (profile
              folders stay)
  version     the turno version, how it was installed, and whether a newer one is known
  completion  shell completion for commands, profiles, identities and config keys

Developer tools
  browser     developer tool: compare browser engines (needs turno-browser)

Examples
  $ turno init                   find your agents, accounts and MCP servers, and set them up
  $ turno                        this folder, your accounts and their usage, and what to do next
  $ turno work                   open the work profile with its agent
  $ turno profile assign . work  make this folder and everything under it use work
  $ turno mcp sync               point every profile at the gateway

Run turno <command> --help, or turno help <command>, for details.
Topics: turno help environment, turno help exit-codes, turno help json.
Scripts and agents: --no-input or TURNO_NO_INPUT=1 never asks (exit 2 instead).
Colors: --color auto|always|never or TURNO_COLOR, then NO_COLOR and FORCE_COLOR.
```
