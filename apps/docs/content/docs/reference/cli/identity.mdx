Who acts on outside services: service accounts (linear:work) and browser identities (browser:school)

```text title="turno identity --help"
Usage:
  turno identity list [--json]  service accounts, browser identities and folder
                                preferences
  turno identity add <service:label> --profile <p> --tools <pattern>[,...]
      [--read-tools <pattern>[,...]] [--confirm always|writes|never] |
      browser:<id> [--timezone <zone>] [--languages <tag,...>] [--health-url
      <url> --health-text <text>] [--dry-run]
                                add a service account, or create a browser
                                identity (browser:<id>)
  turno identity show browser:<id> [--json]
                                a browser identity's settings, session health
                                and who holds it
  turno identity set browser:<id> [--timezone <zone>] [--locale <tag>]
      [--languages <tag,...>] [--region <CC>] [--health-url <url>]
      [--health-text <text>] [--health-selector <css>] [--no-health] [--dry-run]
                                change a browser identity's time zone,
                                languages, region or health check
  turno identity remove <id> [--dry-run]
                                remove a service account, or delete a browser
                                identity and its logins
  turno identity login browser:<id> [--url <url>]
                                open a browser identity's Chrome to sign in by
                                hand once
  turno identity prefer <dir> <service>=<account> [--dry-run]
                                pick the account of a service for a folder
                                (empty account removes it)
  turno identity log [-n N] [--verify] [--json]
                                recent calls to the accounts bridge; --verify
                                checks the log's hash chain

Examples:
  $ turno identity list
  $ turno identity add linear:work --profile work --tools 'mcp__linear__*'
  $ turno identity add browser:school
  $ turno identity login browser:school
  $ turno identity show browser:school
  $ turno identity set browser:school --timezone America/Monterrey --languages es-MX,es,en
  $ turno identity prefer ~/code/acme linear=linear:work
  $ turno identity remove linear:work --dry-run
  $ turno identity log --verify
```
