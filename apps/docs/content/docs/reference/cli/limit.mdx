```text title="turno limit --help"
Usage:
  turno limit show [--watch] [--json]  5 h and weekly usage of each account, as
                                       bars
  turno limit set <profile> [--until "YYYY-MM-DD HH:MM" | --for 2h]
      [--dry-run]
                                       mark a profile exhausted (default for 5
                                       h); its projects open with the fallback,
                                       if one is set
  turno limit clear <profile> [--dry-run]
                                       clear a profile's exhausted mark

Examples:
  $ turno limit show
  $ turno limit show --watch --json  # one JSON line per profile, every 30 s
  $ turno limit set work --for 2h
  $ turno limit clear work
```
