```text title="turno profile --help"
Usage:
  turno profile list [--json]  each profile, its account and roles
  turno profile add <name> [--agent claude|codex|copilot|cursor] [--color
      <c>] [--browser chrome|default] [--dry-run] [--yes] [-v]
                               declare a profile in config.toml and set up its
                               folder and launcher (claude-<name>, codex-<name>,
                               ...); asks before moving your own files aside
                               (--yes skips the question), -v lists every shared
                               item; turno undo reverts all of it
  turno profile repair [profile...] [--yes] [-v]
                               relink shared folders and rewrite launchers (all
                               profiles by default); turno undo reverts it
  turno profile remove [name] [--dry-run]
                               drop a profile from config.toml and its launcher
                               (its folder stays); without a name, choose one
                               and confirm
  turno profile which [dir] [--json] [--check [--agent <agent>]]
                               which profile auto uses in a folder for each
                               agent, and why; --check answers with the exit
                               code instead
  turno profile assign [dir] [profile] [--dry-run]
                               make a folder (and everything under it) use a
                               profile; without a profile, choose one from a
                               list
  turno profile unassign [dir] [--dry-run]
                               remove a folder's own rule

Examples:
  $ turno profile list --json=name,email
  $ turno profile add work
  $ turno profile add school --agent codex --color green
  $ turno profile repair
  $ turno profile remove old --dry-run
  $ turno profile which ~/code/acme
  $ turno profile which --check || turno profile assign . work
  $ turno profile assign ~/code/acme work
  $ turno profile unassign ~/code/acme
```

### turno profile which

```text
Usage:
  turno profile which [dir] [--json] [--check [--agent <agent>]]
    which profile auto uses in a folder for each agent, and why; --check answers
    with the exit code instead

--check prints nothing and exits 0 when the folder has a profile that is set up
and signed in; 3 when it has no profile, 4 when the account is not signed in, 1
when the launcher is missing, with one line on stderr that says why (turno help
exit-codes). It checks the Claude Code profile, or the one of --agent.

Examples:
  $ turno profile which ~/code/acme
  $ turno profile which --check || turno profile assign . work
```
