Read and change config.toml without losing its comments; check every config file.

```text title="turno config --help"
Usage:
  turno config path [--json]            where each config and state file lives
  turno config get [key] [--json]       print a value (the whole file as JSON
                                        without a key)
  turno config set <key> <value> [--dry-run]
                                        set a value, checked like profile add
                                        checks it
  turno config unset <key> [--dry-run]  remove a value
  turno config edit                     open config.toml in $VISUAL or $EDITOR,
                                        then check it
  turno config check                    parse config.toml, mcp.toml and
                                        accounts.toml

Keys:
  system                    profile the plain claude command (~/.claude) is
                            logged into; "" for none (then turno auto needs a
                            rule)
  default                   Claude Code profile for folders without a rule
  fallback                  Claude Code profile used while the assigned one is
                            exhausted (opt-in)
  agents.<agent>.default    the same for codex, copilot or cursor
  agents.<agent>.fallback   the same for codex, copilot or cursor (opt-in)
  icons                     auto, nerd or unicode
  nerd_terminals            terminals whose font draws Nerd icons
  update_check              true or false: look for new turno releases once a
                            day
  open.chrome_dir           folder of the isolated Chrome profiles
  mcpd.port                 port of the MCP gateway
  mcpd.call_log             true or false: keep the log of tool calls (turno mcp
                            log)
  mcpd.max_request_body     largest request mcpd accepts, like "64MiB" (default
                            32MiB)
  mcpd.idle_under_pressure  idle limit of MCP servers while memory is low, like
                            "5m" (default), or false
  profiles.<name>.color     status line pill color
  profiles.<name>.browser   chrome or default

Projects use turno profile assign; MCP servers live in mcp.toml (turno mcp).
A [[projects]] rule with mcp = [...] limits the servers of that folder.

Examples:
  $ turno config path --json
  $ turno config get default
  $ turno config get mcpd --json
  $ turno config set default work
  $ turno config set icons unicode --dry-run
  $ turno config unset fallback
  $ turno config edit
  $ turno config check
```
