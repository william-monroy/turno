MCP servers behind the lazy gateway, and the gateway daemon itself.

```text title="turno mcp --help"
Usage:
```

### turno mcp login

```text
Usage:
  turno mcp login <server> [--profile <p>] [--scope <s>] [--no-browser]
      [--dry-run] [--json]
    log mcpd in to a remote OAuth server, once per variant

For servers declared with auth = "oauth" in mcp.toml. mcpd keeps the tokens in the secret store
(Keychain or Secret Service) and refreshes them; agents reach the server through mcpd.
--profile logs in the variant of that profile ([server.<name>.variant.<profile>]); without one,
the login serves every profile that has no variant of its own.

Examples:
  $ turno mcp login linear --profile work
```

### turno mcp log

```text
Usage:
  turno mcp log [-f] [-n N] [--server S] [--profile P] [--json]
    tool calls mcpd relayed (no arguments or results)

One line per tool call: time, outcome, duration, server, tool, profile, agent and sizes.
-f keeps printing new calls; --json prints one JSON record per line.
Turn the log off with call_log = false under [mcpd] in config.toml.

Examples:
  $ turno mcp log -f --server github
```

### turno mcp top

```text
Usage:
  turno mcp top [--once | --watch] [--json]
    memory, sessions and calls of each running server

Refreshes every 2 seconds in a terminal (Ctrl-C quits); prints one snapshot otherwise.
--watch keeps refreshing anywhere; with --json it prints one snapshot per line (NDJSON).
Exits 5 when mcpd is not running.

Examples:
  $ turno mcp top --watch --json  # one JSON line every 2 s
```

### turno mcp call

```text
Usage:
  turno mcp call <server> [tool] [--args JSON] [--arg k=v ...] [--profile
      <p>] [--json]
    call one tool through mcpd, as a profile's session would

For debugging a server without opening an agent. The call goes through mcpd
with the token of --profile (default: the profile this folder resolves to,
else the system one) and this folder, so tool filters and [[projects]] server
sets apply as they would to an agent here. --args takes a JSON object;
--arg key=value adds a string and --arg key:=json any JSON value. Without a
tool it lists the server's tools. Exits 1 when the tool returns isError, 5
when mcpd is not running.

Examples:
  $ turno mcp call github
  $ turno mcp call github search_issues --arg query=bug --arg limit:=5
  $ turno mcp call fs read_file --args '{"path": "README.md"}' --profile work --json
```

### turno mcp daemon

```text
Usage:
  turno mcp daemon start [--dry-run]    install the service (LaunchAgent or
                                        systemd user unit) and start mcpd
  turno mcp daemon stop [--dry-run]     stop mcpd and remove the service, so it
                                        does not start at login
  turno mcp daemon restart              restart the service (open sessions
                                        reconnect)
  turno mcp daemon status [--json]      running servers, their clients and
                                        memory; why mcpd is down (exit 5)
  turno mcp daemon logs [-n N] [--utc]  last lines of the mcpd log, in local
                                        time
  turno mcp daemon run [--port N]       run the gateway in the foreground (what
                                        the service runs)
  turno mcp daemon token rotate [--dry-run]
                                        replace the gateway token (then turno
                                        mcp sync)

mcpd listens on 127.0.0.1 at mcpd.port (config.toml) and never moves to another port.
start keeps it alive with a LaunchAgent on macOS or a systemd user unit on Linux; stop removes it.

Examples:
  $ turno mcp daemon start
  $ turno mcp daemon status --json
  $ turno mcp daemon restart
  $ turno mcp daemon logs -n 50
  $ turno mcp daemon stop --dry-run
  $ turno mcp daemon run --port 47900
  $ turno mcp daemon token rotate
```

### turno mcp token

```text
Usage: turno mcp token rotate [--dry-run]

Writes a new token (mode 600), restarts mcpd, and asks you to run turno mcp sync.

Examples:
  $ turno mcp token rotate --dry-run
  $ turno mcp token rotate && turno mcp sync
```
