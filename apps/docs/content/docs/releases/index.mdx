## Upgrade

```sh
turno upgrade
```

It recognizes npm, pnpm, bun, yarn and Homebrew installs and runs the matching command. To see the version you have, run `turno version`.

## Versions

turno follows semantic versioning. While it is below 1.0, a minor version (0.3, 0.4) can change behavior, and its page says what changed under "Changed behavior". `turno-cli` and `turno-browser` move together; `turno-core` and `turno-fonts` follow their own numbers.
