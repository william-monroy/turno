A browser your agents can sign in with and carry between machines. `turno-browser` **[signs in to a site without showing the password to the model](/docs/concepts/browser-identities#credential-vault)**, **[moves a signed-in session to another machine](/docs/concepts/browser-identities#moving-a-session)** and **[keeps tabs under control](/docs/concepts/browser-identities#tabs)**. A new look for the CLI and a gateway that does more with less. **[`turno init`](/docs/get-started/first-five-minutes)** sets everything up in one step, **[server sets](/docs/concepts/folder-rules#server-sets-which-mcp-servers-a-folder-sees)** let each folder see only its MCP servers, the gateway signs in to **[remote servers with OAuth](/docs/concepts/gateway#remote-servers)** once per account, and **[`turno mcp top` and `turno mcp log`](/docs/concepts/gateway#watching-it)** show what it does. ## Upgrade

<Upgrade />

To see the version you have, run `turno version`; `turno upgrade --check` only asks the registry whether there is a newer one.

## Versions

turno follows semantic versioning. While it is below 1.0, a minor version (0.3, 0.4) can change behavior, and its page says what changed under "Changed behavior". A patch release has no page of its own: its fixes are in the changelogs. `turno-cli` and `turno-browser` move together; `turno-core` and `turno-fonts` follow their own numbers.
