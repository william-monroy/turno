This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  Google Chrome not found
     manual: install Google Chrome (https://www.google.com/chrome/): turno-browser drives the installed Chrome, not a bundled browser
```

It is a failure; a failure makes `turno browser doctor` exit with code 1.

## Why it happens

turno-browser drives the Google Chrome you have installed. It was not found.

## Fix

Install Google Chrome (https://www.google.com/chrome/): turno-browser drives the installed Chrome, not a bundled browser.

No single command fixes this one, so doctor names the manual step.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
