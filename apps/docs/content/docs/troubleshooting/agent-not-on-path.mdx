This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  <command> not found on PATH, and profiles use it
```

It is a failure; a failure makes `turno doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

A profile belongs to an agent (Claude Code, Codex, Copilot CLI or Cursor CLI), and its launcher runs that agent's own command. The command is not on your PATH, so the launcher has nothing to start.

## Fix


Install the agent. doctor prints the vendor's install command, or the page to follow when there is no one-line install.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/commands/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/commands/doctor.ts).
