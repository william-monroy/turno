This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  the rule for <path> uses profile <profile>, which does not exist
     fix: turno profile add <profile>
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

A `[[projects]]` rule names a profile that turno does not know. `turno auto` in that folder stops with exit code 3 instead of switching to another account in silence.

## Fix

Run:

```sh
turno profile add <profile>
```

`turno doctor --fix` does not run it for you, because it needs a decision or an answer from you.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/core/profiles.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/core/profiles.ts).
