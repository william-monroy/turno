This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  this is an SSH session: a headed Chrome opens only in the signed-in desktop session (where mcpd runs)
     manual: run the browser through mcpd, or pass --headless when you start turno-browser-mcp here
```

It is a warning; warnings do not change the exit code.

## Why it happens

turno-browser drives a headed Chrome, which opens only in the signed-in desktop session, where mcpd runs.

## Fix

Run the browser through mcpd, or pass --headless when you start turno-browser-mcp here.

No single command fixes this one, so doctor names the manual step.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
