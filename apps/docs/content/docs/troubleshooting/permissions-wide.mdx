This page is for when `turno doctor --security` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  permissions: <wide> item<s> under turno's folders <can be changed|can be read> by other users: <writable>
     fix: turno doctor --security --fix
```

It is a failure or a warning; a failure makes `turno doctor --security` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

turno's folders hold gateway tokens, logs and backups, and only you should reach them (folders 0700, files 0600). It is a failure when others can write, a warning when they can only read.

## Fix

Run:

```sh
turno doctor --security --fix
```

This is one of the repairs that flag runs.

Then run `turno doctor --security` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/security.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/security.ts).
