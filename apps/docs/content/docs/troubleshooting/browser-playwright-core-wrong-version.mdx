This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  playwright-core <version> at <dir> is not the version patchright-core is built on, so Camoufox cannot run on it
```

It is a failure or a warning; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

The Camoufox engine loads stock Playwright, and the one found has another minor version than patchright-core. The two share turno's tool code, which only works when the versions match.

## Fix


Install the version doctor names (npm install -g playwright-core@&lt;version&gt;), or point TURNO_PLAYWRIGHT_CORE at a matching copy.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
