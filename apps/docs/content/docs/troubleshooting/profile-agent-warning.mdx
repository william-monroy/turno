This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  profile <name>: <w>
     fix: turno profile repair <name> (turno doctor --fix runs it)
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

The agent's adapter found something that weakens the separation between accounts. Today there is one: a Codex profile whose config.toml does not keep `cli_auth_credentials_store = "file"`, so Codex may keep the login in the shared Keychain instead of inside the profile.

## Fix

Run:

```sh
turno profile repair <name>
```

`turno doctor --fix` runs this repair for you, together with every other one it can.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/commands/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/commands/doctor.ts).
