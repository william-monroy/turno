This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  <server><@<variant>> OAuth: <text>
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

A remote server with `auth = "oauth"` has no usable login for a profile variant: nobody logged in yet, or the authorization server rejected the refresh token. Calls fail until you log in again.

## Fix


turno mcp login &lt;server&gt; (with --profile &lt;p&gt; for a variant). When turno cannot read the secret store at all, install one (macOS Keychain or secret-tool).

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/commands/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/commands/doctor.ts).
