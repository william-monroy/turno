This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  mcpd: port <port> is in use by <describe owner>, so mcpd cannot listen there
     manual: stop that process, or move mcpd: turno config set mcpd.port <port>, then turno mcp sync
```

It is a failure; a failure makes `turno doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

mcpd listens only on `mcpd.port` (47821 by default). If something else holds that port, mcpd does not move: it fails and names the owner.

## Fix

Stop that process, or move mcpd: turno config set mcpd.port &lt;port&gt;, then turno mcp sync.

No single command fixes this one, so doctor names the manual step.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/mcpd/health.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/mcpd/health.ts).
