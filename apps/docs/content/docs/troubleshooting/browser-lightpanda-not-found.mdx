This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  Lightpanda not found, and read mode needs it for <users>
```

It is a failure; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

An identity runs on the Lightpanda engine (identity.json `engine`), and turno found no `lightpanda` on PATH or at TURNO_LIGHTPANDA_PATH. turno never downloads it, so its tool calls fail until you install it or switch the identity back to Chrome.

## Fix


Install Lightpanda with the command doctor prints (on macOS, brew install lightpanda-io/browser/lightpanda), or run turno browser set &lt;id&gt; --engine chrome.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
