This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  Google Chrome not found: claude.ai links open in the default browser
     manual: install Google Chrome, or set TURNO_CHROME_APP to where it is
```

It is a warning; warnings do not change the exit code.

## Why it happens

`turno open` gives each profile its own Chrome profile, so a claude.ai link opens with that profile's account. Without Chrome the link opens in your default browser.

## Fix

Install Google Chrome, or set TURNO_CHROME_APP to where it is.

No single command fixes this one, so doctor names the manual step.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/commands/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/commands/doctor.ts).
