This page is for when `turno doctor --security` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  secret store: none found (no security or secret-tool on PATH)<; mcp.toml has keychain: references that cannot resolve>
```

It is a failure; a failure makes `turno doctor --security` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

MCP secrets live in the macOS Keychain or the Linux Secret Service (secret-tool). Neither is on your PATH. It is a failure only when mcp.toml has `keychain:` references, which cannot resolve without a store.

## Fix


Install secret-tool (libsecret), or write env:NAME in place of each keychain: reference in mcp.toml.

Then run `turno doctor --security` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/security.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/security.ts).
