This page is for when `turno doctor --security` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  audit log: line <line>: <reason>
     manual: find out who changed <audit log> after it was written; turno identity log --verify shows the line
```

It is a failure; a failure makes `turno doctor --security` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

The audit log is append-only and hash-chained: each line carries the hash of the one before. A line does not match, so the file changed after it was written.

## Fix

Find out who changed &lt;audit log&gt; after it was written; turno identity log --verify shows the line.

No single command fixes this one, so doctor names the manual step.

Then run `turno doctor --security` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/security.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/security.ts).
