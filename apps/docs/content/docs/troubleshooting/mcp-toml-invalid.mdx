This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  mcpd: mcp.toml is invalid, serving the <source>: <error>
     manual: correct <mcp file> where the error points, then turno mcp daemon restart
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

When mcp.toml stops validating, mcpd keeps serving the last copy that did (mcp.last-good.toml in turno's state folder) and reports the error.

## Fix

Correct &lt;mcp file&gt; where the error points, then turno mcp daemon restart.

No single command fixes this one, so doctor names the manual step.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/mcpd/health.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/mcpd/health.ts).
