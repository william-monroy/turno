This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  mcpd: <shown> runs a versioned path (<program>) that breaks when that version is removed
     fix: turno mcp daemon start (turno doctor --fix runs it)
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

The service file runs turno from a path that includes a version (a version manager's folder). It breaks when that version is removed.

## Fix

Run:

```sh
turno mcp daemon start
```

`turno doctor --fix` runs this repair for you, together with every other one it can.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/mcpd/health.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/mcpd/health.ts).
