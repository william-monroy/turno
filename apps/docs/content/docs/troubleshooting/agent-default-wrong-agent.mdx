This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  agents.<id>.<role> = "<name>", but <name> is a <label> profile
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

`[agents.<agent>]` holds the default and fallback profile of Codex, Copilot CLI or Cursor CLI. The profile it names belongs to a different agent, so turno cannot open it for this one.

## Fix


Edit config.toml at the line doctor names (or run turno config edit) and name a profile of that agent.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/core/profiles.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/core/profiles.ts).
