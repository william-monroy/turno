This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  <bin> is not on your PATH, so launchers like <launcher name> will not be found (turno <names> works meanwhile)
     manual: <to lower case><advice>, then open a new terminal
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

turno writes one launcher per profile (claude-work, codex-cx) into ~/.local/bin. That folder is not on your PATH, so the shell does not find them. `turno <profile>` works meanwhile.

## Fix

&lt;to lower case&gt;&lt;advice&gt;, then open a new terminal.

No single command fixes this one, so doctor names the manual step.

Add the line doctor prints to your shell profile, then open a new terminal.

Then run `turno doctor` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/commands/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/commands/doctor.ts).
