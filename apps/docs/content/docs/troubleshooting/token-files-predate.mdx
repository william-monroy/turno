This page is for when `turno doctor --security` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  <stale> profile token file< predates|s predate> the mcpd token, so <its agent|their agents> cannot reach mcpd (<stale>)
     fix: turno mcp sync
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

The token files that the launchers of Codex, Copilot CLI and Cursor CLI read were derived from an earlier master token, so those agents cannot reach mcpd.

## Fix

Run:

```sh
turno mcp sync
```

`turno doctor --security --fix` does not run it for you, because it needs a decision or an answer from you.

Then run `turno doctor --security` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/security.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/security.ts).
