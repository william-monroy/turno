This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  playwright-core not found, and Camoufox runs on stock Playwright (patchright-core drives Chromium only): needed for <who>
```

It is a failure; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

Camoufox is a Firefox build. patchright-core, which turno-browser drives Chrome with, cannot drive Firefox, so the Camoufox engine runs on stock Playwright (the playwright-core package) of the same minor version. It was not found next to turno-browser or at TURNO_PLAYWRIGHT_CORE.

## Fix


Install it with the command doctor prints (npm install -g playwright-core@&lt;version&gt;), or set TURNO_PLAYWRIGHT_CORE to its package folder.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
