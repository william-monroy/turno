This page is for when `turno doctor --security` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  permissions: <foreign> item<s> under turno's folders belong to another user (a sudo run?): <foreign>
     manual: give them back to your user: sudo chown -R "$(id -un)" <path> for each one listed
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

Something under turno's folders belongs to another user, usually after a command was run with sudo.

## Fix

Give them back to your user: sudo chown -R "$(id -un)" &lt;path&gt; for each one listed.

No single command fixes this one, so doctor names the manual step.

Then run `turno doctor --security` again to see the row turn into `ok`.

The check lives in [`packages/turno/src/cli/security.ts`](https://github.com/wimo-dev/turno/blob/main/packages/turno/src/cli/security.ts).
