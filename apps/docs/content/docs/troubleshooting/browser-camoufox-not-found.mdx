This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  Camoufox not found, and the camoufox engine needs it for <who>
```

It is a failure; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

An identity runs on the Camoufox engine (identity.json `engine`), and turno found no Camoufox at TURNO_CAMOUFOX_PATH or in the cache folder of Camoufox's own installer. turno never downloads it, so the browser does not start until you install it or switch the identity back to Chrome.

## Fix


Install Camoufox with the command doctor prints (pip install -U camoufox &amp;&amp; camoufox fetch), set TURNO_CAMOUFOX_PATH if turno does not find it, or run turno browser set &lt;id&gt; --engine chrome.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
