This page is for when `turno doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  <name> reads <list> from mcpd's environment, and <it is|they are> not set here
     manual: set <list> where mcpd starts, then turno mcp daemon restart; or store <it|each> with turno secret set <name> and write keychain:<name> instead
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

A server in mcp.toml reads `env:NAME` or `${NAME}` from mcpd's environment. The variable is not set in the shell doctor runs in. A variable that is unset and has no default stops that server from starting.

## Fix

Set &lt;list&gt; where mcpd starts, then turno mcp daemon restart; or store &lt;it\|each&gt; with turno secret set &lt;name&gt; and write keychain:&lt;name&gt; instead.

No single command fixes this one, so doctor names the manual step.

Then run `turno doctor` again to see the row turn into `ok`.
